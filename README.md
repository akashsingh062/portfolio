## 📖 About The Project

This portfolio is designed to represent my work, technical skills, and journey as a developer in a visually engaging and interactive way. It focuses on performance, clean architecture, responsive design, and smooth user interactions.

Built using **Next.js 16 App Router**, **React 19**, **TypeScript**, and **Tailwind CSS**, the project combines modern UI design with optimized frontend engineering practices.

---

## ✨ Features

- ⚡ **Fast Performance**  
  Built with Next.js for optimized rendering, routing, and image delivery.

- 🎨 **Modern UI/UX Design**  
  Clean layouts, glassmorphism effects, gradients, and polished design components.

- 🌙 **Dark / Light Mode Support**  
  Seamless theme switching with persistent user preference.

- 📱 **Fully Responsive Design**  
  Optimized for mobile, tablet, laptop, and desktop screens.

- 🎬 **Smooth Animations**  
  Interactive transitions and micro-interactions powered by Motion.

- 🧩 **Reusable Component Architecture**  
  Modular and scalable code structure for maintainability.

- ✉️ **Functional Contact Form**  
  Integrated with Web3Forms for serverless form submissions.

- 🚀 **SEO Optimized**  
  Metadata configuration for better search engine visibility.

- 🖼️ **Interactive UI Components**
  - Floating dock navigation
  - Animated profile image effects
  - Particle background effects
  - Gradient highlights and glow effects

## 🚀 Getting Started

To run this project locally, follow these steps:

### 1. Clone the repository

```bash
git clone https://github.com/akashsingh062/portfolio.git
cd portfolio
```

### 2. Install dependencies

```bash
npm install
# or
bun install
```

### 3. Setup environment variables

Create a `.env.local` file in the root directory and add your Web3Forms access key (if you want to use the functional contact form):

```env
NEXT_PUBLIC_WEB3FORMS_ACCESS_KEY=your-access-key-here
```

### 4. Run the development server

```bash
npm run dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see your local copy.
